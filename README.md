# Strawberry Snail

Entry for make.fun **cutest-picture-01**.

A cream-coloured snail carries a giant ripe strawberry on its back. Drawn by
concept_e3.py (pure Python stdlib). The rules allow the simplest program: the
repository holds the image and the program copies it.

## Run

```sh
python main.py            # writes /output/entry.png
python main.py --check    # prints sha256
```
